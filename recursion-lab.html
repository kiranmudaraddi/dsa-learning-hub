1. What is recursion?

Recursion is a problem-solving technique in which a function calls itself to solve a smaller version of the same problem.

🛑 Base case — stop

The condition that ends the recursive calls. Without a valid base case, recursion may continue until a stack overflow occurs.

if (n <= 1) return 1;

🔁 Recursive case — reduce

The function calls itself with a smaller input that moves toward the base case.

return n * factorial(n - 1);
Remember: Every recursive function needs a stopping condition and progress toward that condition.

2. C program: factorial

int factorial(int n) { if (n <= 1) return 1; // base case return n * factorial(n - 1); // recursive case }

Factorial: 4! = 4 × 3 × 2 × 1 = 24

4. Visualize the call sequence

For factorial(4), calls move downward until factorial(1). Return values then move upward.

factorial(4) = 4 × factorial(3) = 3 × factorial(2) = 2 × factorial(1) = 1 // base case = 2 × 1 = 2 = 3 × 2 = 6 = 4 × 6 = 24

The call stack follows LIFO: the most recent call is the first one to finish.

5. Another example: sum from 1 to n

int sum(int n) { if (n <= 0) return 0; // base case return n + sum(n - 1); }

Example: sum(4) = 4 + 3 + 2 + 1 + 0 = 10.

Try to explain: Why does sum(0) return 0? What would happen if the base case were removed?
