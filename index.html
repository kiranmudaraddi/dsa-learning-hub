01

Introduction to Data Structures

A data structure is a systematic way of organizing, storing and accessing data so that operations such as searching, inserting and deleting can be performed efficiently. Choosing a suitable data structure affects a program’s speed and memory use.

1.1 Basic terms

TermMeaningExample
DataRaw facts or values85, “Asha”, 3.14
Data itemSmallest meaningful unit of dataA student’s roll number
RecordRelated data items collected togetherRoll number, name and marks
Data typeValues and operations permitted on themint, float, char
Data structureOrganized collection of data and operationsArray, stack, structure
Abstract Data Type (ADT)Defines what operations are provided, not how they are implementedStack ADT: push, pop, peek

1.2 Classification of data structures

BasisCategoryDescription and examples
Nature of dataPrimitiveBasic language types: int, float, char, double, pointer
Nature of dataNon-primitiveBuilt from primitive types: array, structure, stack, queue, linked list
ArrangementLinearElements form a sequence: array, stack, queue, linked list
ArrangementNon-linearHierarchical or network arrangement: tree, graph
Memory sizeStaticSize fixed in advance: array
Memory sizeDynamicCan grow or shrink at runtime: linked list, dynamically allocated arrays
Element typesHomogeneousSame element type: array
Element typesHeterogeneousDifferent member types: structure
Remember: Arrays, stacks and queues are linear structures. Trees and graphs are non-linear structures.

1.3 Data structure operations

OperationMeaningExample on [10, 20, 30, 40]
TraversingVisit every element to process itPrint all four elements
InsertingAdd an element at a positionInsert 25: [10, 20, 25, 30, 40]
DeletingRemove an elementDelete 20: [10, 30, 40]
SearchingFind the location of a valueFind 30 at index 2 (after insertion, indices may change)
SortingArrange values in an orderDescending: [40, 30, 20, 10]

1.4 Array insertion and deletion

Array elements occupy consecutive memory locations. Inserting or deleting in the middle therefore requires shifting later elements.

Insert x at position pos (0-based)

  1. Check that the array has space and that 0 ≤ pos ≤ n.
  2. Shift elements right, from index n−1 down to pos.
  3. Store x at a[pos].
  4. Increase the element count n.
for (i = n - 1; i >= pos; i--)
    a[i + 1] = a[i];
a[pos] = x;
n++;

Example: Insert 25 at index 2 in [10, 20, 30, 40]. Shift 40 and 30 right, then place 25 → [10, 20, 25, 30, 40].

Delete the element at position pos

  1. Check that 0 ≤ pos < n.
  2. Shift following elements left, from pos to n−2.
  3. Decrease n by one.
for (i = pos; i < n - 1; i++)
    a[i] = a[i + 1];
n--;

1.5 Time complexity of array operations

OperationBest / typicalWorst caseReason
TraversingO(n)O(n)Every element is visited
Insert at endO(1)O(1), if space existsNo shifting needed
Insert at position / beginningO(1) at endO(n)Later elements shift right
Delete at positionO(1) for last elementO(n)Later elements shift left
Linear searchO(1)O(n)Target may be last or absent
Binary search (sorted array)O(1)O(log n)Search range halves each step
MODULE I · STRUCTURES IN C
02

Structures in C

An array stores elements of the same type. A structure groups variables of different types under one name, allowing related details about one entity to be handled together. Each variable inside a structure is a member.

2.1 Definition and declaration

struct student
{
    int roll;
    char name[20];
    float marks;
};  /* semicolon is mandatory */

struct student s1, s2;

The structure definition creates a type; memory is allocated when structure variables are declared. The compiler may add padding for alignment.

2.2 Accessing members: dot and arrow

struct student s1 = {101, "Asha", 82.5};
struct student *p = &s1;

printf("%d %s %.1f\n", s1.roll, s1.name, s1.marks);
printf("%d %s %.1f\n", p->roll, p->name, p->marks);

/* p->marks is the same as (*p).marks */

Use the dot operator (.) with a structure variable and the arrow operator (->) with a pointer to a structure.

2.3 typedef with structures

typedef struct
{
    int roll;
    char name[20];
    float marks;
} STUDENT;

STUDENT s1, s2;

typedef gives the structure type a shorter name, so the keyword struct need not be repeated for variables declared as STUDENT.

2.4 Types of structures

TypeDescriptionExample
Simple structureMembers are basic types or arraysStudent with roll and marks
Nested structureA member is itself a structureEmployee with date of birth
Array of structuresMany records of one structure typestruct student s[50];
Pointer to structurePointer stores a structure's addressstruct student *p = &s1;
Self-referential structureContains a pointer to the same structure typeLinked-list node
struct date { int day, month, year; };

struct employee
{
    int id;
    char name[20];
    struct date dob;
};

struct employee e = {1, "Ravi", {15, 8, 2001}};
printf("%d", e.dob.year);  /* 2001 */

2.5 Array of structures: student record example

Each array element is one complete student record. The program reads three students, displays the records, calculates average marks and finds the topper.

#include 
#define N 3

struct student {
    int roll;
    char name[20];
    float marks;
};

int main(void)
{
    struct student s[N];
    int i, top = 0;
    float total = 0;

    for (i = 0; i < N; i++) {
        printf("Enter roll, name, marks: ");
        scanf("%d %19s %f", &s[i].roll, s[i].name, &s[i].marks);
        total += s[i].marks;
        if (i == 0 || s[i].marks > s[top].marks)
            top = i;
    }

    printf("\nRoll\tName\tMarks\n");
    for (i = 0; i < N; i++)
        printf("%d\t%s\t%.2f\n", s[i].roll, s[i].name, s[i].marks);

    printf("Average = %.2f\n", total / N);
    printf("Topper = %s (%.2f)\n", s[top].name, s[top].marks);
    return 0;
}
Sample input: 1 Asha 82.5, 2 Ravi 74, 3 Meena 91. Output average = 82.50; topper = Meena (91.00).

2.6 Structure versus union

PointStructureUnion
Keywordstructunion
MemorySeparate storage for every member; padding may applyShared memory; size accommodates the largest member plus alignment
ValuesMembers can hold values simultaneouslyOnly one member's stored value is meaningful at a time
Typical useStudent or employee recordsMemory saving when alternative data forms share storage

Common mistakes

  • Forgetting the semicolon after the closing brace of the definition.
  • Comparing two structures with ==; compare members individually instead.
  • Using &s[i].name for a character array in scanf; use s[i].name and a width limit such as %19s.
  • Using dot with a pointer instead of p->roll or (*p).roll.

Stack: Last In, First Out (LIFO)

A stack is a linear data structure in which insertion and deletion take place at one end called the top. The element inserted last is removed first. A pile of plates is a common analogy.

Push 10→Push 20→Push 30→Pop returns 30

3.1 Stack operations

OperationPurposeCondition
push(x)Insert x at the topOverflow if full: top == MAX−1
pop()Remove and return the top elementUnderflow if empty: top == −1
peek() / topRead top without removing itStack must not be empty
isEmpty()Check whether stack has no elementstop == −1
isFull()Check whether stack is fulltop == MAX−1

3.2 Array representation and algorithms

Use an array stack[MAX] and an integer top storing the index of the topmost element. Initially, top = -1 means empty.

PUSH(x)

  1. If top == MAX−1, report Stack Overflow and stop.
  2. Increment top.
  3. Store x in stack[top].

POP()

  1. If top == −1, report Stack Underflow and stop.
  2. Read x = stack[top].
  3. Decrement top and return x.

3.3 Complete C program

#include 
#define MAX 5

int stack[MAX];
int top = -1;

void push(int x)
{
    if (top == MAX - 1)
        printf("Stack Overflow\n");
    else
        stack[++top] = x;
}

int pop(void)
{
    if (top == -1) {
        printf("Stack Underflow\n");
        return -1; /* sentinel for this example */
    }
    return stack[top--];
}

int peek(void)
{
    if (top == -1) {
        printf("Stack is empty\n");
        return -1;
    }
    return stack[top];
}

void display(void)
{
    int i;
    if (top == -1)
        printf("Stack is empty\n");
    else
        for (i = top; i >= 0; i--)
            printf("%d\n", stack[i]);
}

int main(void)
{
    push(10);
    push(20);
    push(30);
    printf("Popped: %d\n", pop());
    push(40);
    printf("Top: %d\n", peek());
    display();
    return 0;
}

Output

Popped: 30
Top: 40
40
20
10

3.4 Trace stack operations

OperationtopStack (bottom → top)Result
Start−1empty—
push(10)010—
push(20)110, 20—

3.5 Complexity and limitations

  • push, pop, peek, isEmpty and isFull each take O(1) time.
  • An array stack has fixed capacity. Pushing into a full stack causes overflow.
  • A linked-list stack can avoid a fixed array capacity, but uses dynamic memory.

Common mistakes

  • Forgetting overflow or underflow checks.
  • Starting top at 0 when using −1 to represent an empty stack.
  • Using −1 as an error result even though −1 might be a valid stack item.

Infix, Postfix and Prefix Expressions

An expression combines operands (values or variables) and operators such as +, −, *, /, % and ^.

MODULE II · STACK APPLICATIONS
05

Infix to Postfix Conversion

Scan the expression from left to right. Output operands immediately and hold operators on a stack until precedence and associativity allow them to be output.

5.1 Algorithm

  1. Initialize an empty operator stack and output string.
  2. Read the next symbol.
  3. If it is an operand, append it to output.
  4. If it is an opening parenthesis, push it.
  5. If it is a closing parenthesis, pop operators to output until an opening parenthesis is found; discard both parentheses.
  6. If it is an operator, pop higher-precedence operators. Also pop equal-precedence operators when the current operator is left-associative; then push the current operator.
  7. Repeat for all symbols, then pop remaining operators. Unmatched parentheses indicate an invalid expression.

5.2 Worked example: A + B * (C - D)

SymbolActionStack (bottom → top)Output
AOutput operand—A
+Push+A
BOutput operand+AB
*Push+*AB
(Push+*(AB
COutput operand+*(ABC
−Push+*(−ABC
DOutput operand+*(−ABCD
)Output −; discard (+*ABCD−
EndOutput * then +—ABCD−*+
Result: ABCD−*+. Do not output parentheses, and do not forget to pop remaining operators at the end.

5.3 Common mistakes

  • Including parentheses in the postfix output.
  • Forgetting remaining operators after scanning the expression.
  • Ignoring precedence or associativity.
  • Using a single-character scanner for expressions containing multi-digit numbers, spaces or unary minus without tokenization.

5.4 Infix to prefix conversion

  1. Reverse the infix expression.
  2. Swap each opening parenthesis with a closing parenthesis and vice versa.
  3. Convert the modified expression to postfix, adjusting associativity carefully.
  4. Reverse the postfix result to obtain prefix.
  5. Check the grouping and operator order.

Example: Infix (A + B) * C → reverse and swap: C * (B + A) → postfix: CBA+* → reverse: *+ABC.

Expressions containing exponentiation or equal-precedence operators require careful associativity handling; do not apply reversal mechanically.
MODULE II · EXPRESSION EVALUATION
06

Postfix / Suffix Evaluation

Postfix evaluation uses a stack of values. Operands are pushed; when an operator appears, pop the operands, calculate, and push the result.

6.1 Algorithm

  1. Create an empty stack of values.
  2. Scan tokens from left to right.
  3. If a token is an operand, convert it to a value and push it.
  4. If a token is an operator, pop operand2 first, then operand1.
  5. Calculate operand1 operator operand2 and push the result.
  6. After scanning, exactly one value should remain. Check for insufficient operands, extra values and division by zero.

6.2 Worked example: 23*54*+

TokenActionStack (bottom → top)
2Push 22
3Push 32, 3
*2 × 3 = 66
5Push 56, 5
4Push 46, 5, 4
*5 × 4 = 206, 20
+6 + 20 = 2626

Final result = 26.

6.3 Operand order matters

For postfix 82-, pop 2 first as operand2 and 8 second as operand1. Calculate 8 − 2 = 6. The order is important for subtraction and division.

A character-by-character C program may support single-digit operands. For multi-digit numbers or identifiers, tokenize the expression (for example, use spaces between tokens). Always check stack underflow and division by zero.

MODULE II · RECURSION
07

Recursion

Recursion occurs when a function calls itself to solve a smaller instance of the same problem. Every correct recursive solution needs a base case and a recursive case.

Base case

The stopping condition. It returns a result without making another recursive call.

Recursive case

A call that reduces the problem and moves toward the base case.

7.1 Factorial example

int factorial(int n)
{
    if (n <= 1)
        return 1;             /* base case */
    return n * factorial(n - 1);
}

factorial(4) = 4 × factorial(3) = 4 × 3 × factorial(2) = 4 × 3 × 2 × factorial(1) = 24.

7.2 Sum from 1 to n

int sum(int n)
{
    if (n <= 0)
        return 0;
    return n + sum(n - 1);
}

sum(4) = 4 + 3 + 2 + 1 + 0 = 10.

7.3 Recursion and the call stack

Each function call stores information such as parameters, local variables and the return location in a call-stack frame. Calls return in LIFO order.

factorial(4)→factorial(3)→factorial(2)→factorial(1)

Return flow unwinds in reverse order: factorial(1) → factorial(2) → factorial(3) → factorial(4).

7.4 Uses and limitations

  • Useful for tree traversals, factorial, divide-and-conquer and backtracking.
  • Can express naturally recursive problems clearly.
  • Function calls consume time and stack memory.
  • Deep or infinite recursion may cause stack overflow; ensure each call progresses toward the base case.

8.2 Case study: Undo in a text editor

Each edit is pushed onto an undo stack. Pressing Undo pops the most recent edit and reverses it. Redo can use a second stack to receive the edits that were undone.

8.3 Case study: Checking balanced parentheses

Scan the expression left to right. Push each opening parenthesis. When a closing parenthesis appears, pop one opening parenthesis. If the stack is empty before a pop, the expression is unbalanced. At the end, the expression is balanced only if the stack is empty.

Read symbol→Opening bracket?→Push/Closing bracket?→Pop

Example: (A+B)*(C is unbalanced because one opening parenthesis was never closed.

  • Inserting: add a new student record.
  • Deleting: remove a student; later array elements shift left.
  • Searching: find a student by roll number.
  • Sorting: produce a rank list by marks.

Quick revision and practice

Key points to remember

  • A data structure organizes data for efficient operations; an ADT describes behaviour, not implementation.
  • Linear structures include arrays, stacks and queues. Trees and graphs are non-linear.
  • Array insertion and deletion can take O(n) time in the worst case because of shifting.
  • A structure groups members of different types; use . with variables and -> with pointers.
  • A stack is LIFO. For an array stack, top = -1 means empty and top = MAX-1 means full.
  • Infix needs precedence rules; postfix and prefix encode operator order explicitly.
  • Every recursive function needs a base case and a recursive case.
1. Which principle does a stack follow?
2. What does top = −1 indicate in the array stack implementation?
3. What is the postfix form of A + B * C?
4. Which two parts does a correct recursive solution need?
