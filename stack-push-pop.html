Array Representation of Stack

Learn and visualize PUSH, POP, DISPLAY, Overflow and Underflow

1. Basic Idea

Stack follows LIFO: Last In, First Out.
Insertion and deletion take place only at the TOP.

For an array stack:

#define MAX 5 int stack[MAX]; int top = -1;

top = -1 means the stack is empty.

4. PUSH Function

To insert an element, first check whether the stack is full.

void push() { int value; if (top == MAX - 1) { printf("Stack Overflow"); return; } printf("Enter value: "); scanf("%d", &value); top++; stack[top] = value; }
Logic:
1. Check top == MAX - 1.
2. If true → Overflow.
3. Otherwise increment top.
4. Store the value at stack[top].

5. POP Function

To delete an element, remove the element at TOP.

void pop() { int value; if (top == -1) { printf("Stack Underflow"); return; } value = stack[top]; top--; printf("Deleted = %d", value); }
Logic:
1. Check top == -1.
2. If true → Underflow.
3. Otherwise access stack[top].
4. Decrement top.

6. DISPLAY Function

Display starts from TOP and moves towards index 0.

void display() { int i; if (top == -1) { printf("Stack is Empty"); return; } for (i = top; i >= 0; i--) { printf("%d ", stack[i]); } }
Important: A stack is normally displayed from TOP → bottom.

7. Overflow

Overflow: Trying to PUSH when the stack is already full.
if (top == MAX - 1) { printf("Stack Overflow"); return; }

For MAX = 5, valid indexes are 0, 1, 2, 3, 4.

When top = 4, the stack is full.

8. Underflow

Underflow: Trying to POP when the stack is empty.
if (top == -1) { printf("Stack Underflow"); return; }

Initially top = -1, so there is no element to delete.

9. Complete C Program

#include <stdio.h> #define MAX 5 int stack[MAX]; int top = -1; void push() { int value; if (top == MAX - 1) { printf("\nStack Overflow"); return; } printf("Enter value: "); scanf("%d", &value); top++; stack[top] = value; printf("Pushed successfully."); } void pop() { int value; if (top == -1) { printf("\nStack Underflow"); return; } value = stack[top]; top--; printf("\nDeleted = %d", value); } void display() { int i; if (top == -1) { printf("\nStack is Empty"); return; } printf("\nStack elements (TOP to bottom): "); for (i = top; i >= 0; i--) { printf("%d ", stack[i]); } } int main() { int choice; do { printf("\n\n--- ARRAY STACK ---"); printf("\n1. PUSH"); printf("\n2. POP"); printf("\n3. DISPLAY"); printf("\n4. EXIT"); printf("\nEnter choice: "); scanf("%d", &choice); switch(choice) { case 1: push(); break; case 2: pop(); break; case 3: display(); break; case 4: printf("\nExit"); break; default: printf("\nInvalid choice"); } } while(choice != 4); return 0; }
