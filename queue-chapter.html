1. Queue fundamentals

A queue is a linear data structure that follows FIFO (First In, First Out). Insert at the REAR; remove from the FRONT.

Everyday example

At a ticket counter, the first person to join the line is served first.

Applications

Printer jobs, service requests, CPU scheduling, network buffers, breadth-first search.

Array representation

Store values in Q[0...MAX-1] and track them using front and rear. Initially both are -1. For a simple linear queue, empty is front == -1; full is rear == MAX-1.

Limitation: after deletions, a simple linear queue may not reuse empty slots before FRONT. A circular queue solves this by wrapping indices around.

2. Operations and algorithms

Enqueue(item)

  1. If rear == MAX−1, report OVERFLOW and stop.
  2. If front == −1, set front = 0.
  3. rear = rear + 1.
  4. Q[rear] = item.

Dequeue()

  1. If front == −1 or front > rear, report UNDERFLOW.
  2. item = Q[front].
  3. If front == rear, reset both to −1; otherwise front = front + 1.
  4. Return item.

Peek/Front: read Q[front] without deleting, after checking that the queue is not empty. Display: print elements from FRONT through REAR.

Enqueue flowchart

START→rear == MAX−1?YES →Print OVERFLOW→STOP

NO branch: if front == −1, set front = 0 → rear = rear + 1 → Q[rear] = item → STOP.

Dequeue flowchart

START→Queue empty?YES →Print UNDERFLOW→STOP

NO branch: item = Q[front] → if front == rear reset both to −1, else increment front → return item → STOP.

Formal flowchart symbols: oval = Start/Stop, diamond = decision, rectangle = processing, parallelogram = input/output.

3. Linear queue — C code snippets

Initialization

#include <stdio.h>
#define MAX 5
int q[MAX];
int front = -1, rear = -1;

Enqueue

void enqueue(int item) {
    if (rear == MAX - 1) {
        printf("Queue Overflow\\n");
        return;
    }
    if (front == -1) {
        front = 0;
    }
    rear++;
    q[rear] = item;
}

Dequeue

void dequeue(void) {
    if (front == -1 || front > rear) {
        printf("Queue Underflow\\n");
        return;
    }
    int item = q[front];
    printf("Deleted: %d\\n", item);

    if (front == rear) {
        front = rear = -1;
    } else {
        front++;
    }
}

Display

void display(void) {
    if (front == -1) {
        printf("Queue is empty\\n");
        return;
    }
    for (int i = front; i <= rear; i++) {
        printf("%d ", q[i]);
    }
    printf("\\n");
}

Complete menu-driven program

#include <stdio.h>
#define MAX 5

int q[MAX], front = -1, rear = -1;

void enqueue(int item) {
    if (rear == MAX - 1) {
        puts("Queue Overflow");
        return;
    }
    if (front == -1) front = 0;
    q[++rear] = item;
}

void dequeue(void) {
    if (front == -1 || front > rear) {
        puts("Queue Underflow");
        return;
    }
    printf("Deleted: %d\\n", q[front]);
    if (front == rear) front = rear = -1;
    else front++;
}

void peek(void) {
    if (front == -1) puts("Queue is empty");
    else printf("Front item: %d\\n", q[front]);
}

void display(void) {
    if (front == -1) { puts("Queue is empty"); return; }
    for (int i = front; i <= rear; i++) printf("%d ", q[i]);
    puts("");
}

int main(void) {
    int choice, value;
    do {
        printf("\\n1.Enqueue  2.Dequeue  3.Peek  4.Display  5.Exit\\n");
        printf("Choice: ");
        if (scanf("%d", &choice) != 1) return 0;
        switch (choice) {
            case 1:
                printf("Value: ");
                if (scanf("%d", &value) != 1) return 0;
                enqueue(value); break;
            case 2: dequeue(); break;
            case 3: peek(); break;
            case 4: display(); break;
            case 5: puts("Exit"); break;
            default: puts("Invalid choice");
        }
    } while (choice != 5);
    return 0;
}

Implementation of Circular Queue

A circular queue reuses freed array positions by wrapping indices from MAX-1 back to 0. It avoids the unused-slot problem found in a simple linear array queue.

Empty condition

front == -1

Full condition

(rear + 1) % MAX == front

Enqueue algorithm

if ((rear + 1) % MAX == front) { puts("Queue Overflow"); return; }
if (front == -1) front = rear = 0;
else rear = (rear + 1) % MAX;
q[rear] = item;

Dequeue algorithm

if (front == -1) { puts("Queue Underflow"); return; }
item = q[front];
if (front == rear) front = rear = -1;
else front = (front + 1) % MAX;

Complete circular queue C program

#include <stdio.h>
#define MAX 5
int q[MAX], front = -1, rear = -1;

void enqueue(int item) {
    if ((rear + 1) % MAX == front) {
        puts("Queue Overflow"); return;
    }
    if (front == -1) front = rear = 0;
    else rear = (rear + 1) % MAX;
    q[rear] = item;
}
void dequeue(void) {
    if (front == -1) { puts("Queue Underflow"); return; }
    printf("Deleted: %d\\n", q[front]);
    if (front == rear) front = rear = -1;
    else front = (front + 1) % MAX;
}
void display(void) {
    if (front == -1) { puts("Queue is empty"); return; }
    int i = front;
    while (1) {
        printf("%d ", q[i]);
        if (i == rear) break;
        i = (i + 1) % MAX;
    }
    puts("");
}
int main(void) {
    int ch, x;
    do {
        printf("\\n1.Enqueue 2.Dequeue 3.Display 4.Exit\\n");
        scanf("%d", &ch);
        switch (ch) {
            case 1: printf("Value: "); scanf("%d", &x); enqueue(x); break;
            case 2: dequeue(); break;
            case 3: display(); break;
            case 4: puts("Exit"); break;
            default: puts("Invalid choice");
        }
    } while (ch != 4);
    return 0;
}

DEQueues (Double-Ended Queues)

A deque allows insertion and deletion at both FRONT and REAR.

Input-restricted deque

Insertion at only one end; deletion at both ends.

Output-restricted deque

Deletion at only one end; insertion at both ends.

Core operations in a circular array

insertFront(x):
    if full: report OVERFLOW
    if empty: front = rear = 0
    else: front = (front - 1 + MAX) % MAX
    Q[front] = x

insertRear(x):
    if full: report OVERFLOW
    if empty: front = rear = 0
    else: rear = (rear + 1) % MAX
    Q[rear] = x

deleteFront():
    if empty: report UNDERFLOW
    save Q[front]
    if front == rear: front = rear = -1
    else: front = (front + 1) % MAX

deleteRear():
    if empty: report UNDERFLOW
    save Q[rear]
    if front == rear: front = rear = -1
    else: rear = (rear - 1 + MAX) % MAX

Applications include sliding-window algorithms, task scheduling, and buffers that require both-end access. Each of the four end operations takes O(1) time in a circular-array implementation.

Priority Queues

A priority queue serves items according to priority rather than arrival order alone. This example defines a smaller priority number as more urgent; equal priorities retain FIFO order.

ImplementationInsertRemove highest priorityPeek
Unsorted arrayO(1)O(n)O(n)
Sorted arrayO(n)O(1)O(1)
Binary heapO(log n)O(log n)O(1)

Simple C implementation using a sorted array

#include <stdio.h>
#define MAX 5
struct Item { int value, priority; };
struct Item pq[MAX];
int size = 0;

/* Smaller priority number = more urgent */
void insert(int value, int priority) {
    int i;
    if (size == MAX) { puts("Priority Queue Overflow"); return; }
    i = size - 1;
    while (i >= 0 && pq[i].priority > priority) {
        pq[i + 1] = pq[i]; i--;
    }
    pq[i + 1].value = value;
    pq[i + 1].priority = priority;
    size++;
}
void deleteHighestPriority(void) {
    int i;
    if (size == 0) { puts("Priority Queue Underflow"); return; }
    printf("Served value %d, priority %d\\n", pq[0].value, pq[0].priority);
    for (i = 0; i < size - 1; i++) pq[i] = pq[i + 1];
    size--;
}
void display(void) {
    int i;
    if (size == 0) { puts("Priority queue is empty"); return; }
    for (i = 0; i < size; i++)
        printf("Value=%d Priority=%d\\n", pq[i].value, pq[i].priority);
}
int main(void) {
    int ch, value, priority;
    do {
        printf("\\n1.Insert 2.Delete highest priority 3.Display 4.Exit\\n");
        scanf("%d", &ch);
        switch (ch) {
            case 1: printf("Value and priority: "); scanf("%d%d", &value, &priority); insert(value, priority); break;
            case 2: deleteHighestPriority(); break;
            case 3: display(); break;
            case 4: puts("Exit"); break;
            default: puts("Invalid choice");
        }
    } while (ch != 4);
    return 0;
}

Example: insert (101, 3), (102, 1), (103, 2). Removal order is 102, then 103, then 101.

4. Circular queue

A circular queue treats the array as a ring. The index wraps to zero using modulo arithmetic.

Empty: front == -1
Full: (rear + 1) % MAX == front

Enqueue algorithm

If full, report overflow. If empty, set front = rear = 0; otherwise set rear = (rear + 1) % MAX. Store Q[rear] = item.

Dequeue algorithm

If empty, report underflow. Save Q[front]. If front == rear, reset both to −1; otherwise set front = (front + 1) % MAX.

Circular queue code snippets

/* Enqueue */
if ((rear + 1) % MAX == front) {
    puts("Queue Overflow");
    return;
}
if (front == -1) front = rear = 0;
else rear = (rear + 1) % MAX;
q[rear] = item;

/* Dequeue */
if (front == -1) {
    puts("Queue Underflow");
    return;
}
int item = q[front];
if (front == rear) front = rear = -1;
else front = (front + 1) % MAX;

Complexity: enqueue O(1), dequeue O(1), peek O(1), display O(n).

6. Priority queue

A priority queue removes items based on priority rather than arrival order alone. Define whether smaller or larger numbers represent higher priority. For ties, use a clear rule such as FIFO.

Real-world examples: hospital triage, operating-system scheduling, network traffic management. Implementation choices include an unsorted array, sorted array or heap.

8. Real-world case study — campus service counter

An office issues tokens to students. New tokens are added at the rear; the next token served is removed from the front. A normal queue models first-come, first-served service. A circular queue is suitable for a bounded reusable buffer. A priority queue is appropriate only when urgent requests are explicitly prioritized.

Discussion 1: What happens when dequeue is called on an empty queue?
Discussion 2: How would you show the next token without deleting it?
Discussion 3: Is priority service fair? How should equal-priority requests be handled?
