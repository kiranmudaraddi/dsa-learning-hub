Rules
🟢 Operand / digit → PUSH into stack
🟠 Operator → POP operand2
🔵 Then POP operand1
🟣 Calculate operand1 operator operand2
🟢 PUSH the result back into stack

⚠️ Important

For - and /, order matters:
operand1 = POP()
operand2 = POP()
result = operand1 OP operand2
