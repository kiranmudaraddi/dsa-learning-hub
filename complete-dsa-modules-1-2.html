1. Introduction to Data Structures

A data structure organizes data so it can be accessed and modified efficiently.

Linear

Elements form a sequence: arrays, linked lists, stacks and queues.

Non-linear

Elements form hierarchical or network relationships: trees and graphs.

Common operations

Traversing, inserting, deleting, searching and sorting.

Structures in C

2. Stack — LIFO

A stack follows LIFO (Last In, First Out). Insertion is PUSH; deletion is POP. Both happen at TOP. Applications include function calls, undo operations, expression conversion/evaluation and browser history.

Array representation

#define MAX 5
int stack[MAX];
int top = -1;  /* empty stack */

PUSH algorithm

  1. If top == MAX−1, report overflow.
  2. Otherwise top = top + 1.
  3. stack[top] = item.

POP algorithm

  1. If top == −1, report underflow.
  2. Save stack[top].
  3. Decrement top and return saved value.

Flowchart logic: PUSH

START→top == MAX−1?YES →Overflow→STOP

NO: top++ → stack[top] = item → STOP.

Flowchart logic: POP

START→top == −1?YES →Underflow→STOP

NO: item = stack[top] → top-- → return item → STOP.

Readable C snippets

void push(int item) {
    if (top == MAX - 1) {
        puts("Stack Overflow");
        return;
    }
    stack[++top] = item;
}

void pop(void) {
    if (top == -1) {
        puts("Stack Underflow");
        return;
    }
    int item = stack[top--];
    printf("Removed: %d\\n", item);
}

3. Infix, Postfix and Prefix Expressions

Infix: operator between operands, e.g. A+B. Postfix: operator after operands, e.g. AB+. Prefix: operator before operands, e.g. +AB.

Parentheses and operator precedence determine the order of operations. A stack temporarily holds operators during conversion and operands during evaluation.

Infix to postfix — algorithm outline

  1. Scan the expression from left to right.
  2. Send operands directly to output.
  3. Push '(' onto the stack.
  4. For an operator, pop higher-precedence operators (and equal precedence when left-associative) before pushing it.
  5. On ')', pop until '('; discard the parentheses.
  6. Pop remaining operators to output.

Postfix evaluation — algorithm outline

  1. Scan tokens from left to right.
  2. Push each operand.
  3. For an operator, pop right operand first, then left operand; apply the operator.
  4. Push the result back.
  5. The final stack item is the answer for a valid expression.

Example

Infix (2 + 3) * 4 → postfix 2 3 + 4 * → result 20.

4. Recursion

Recursion occurs when a function calls itself to solve a smaller version of the same problem. Every correct recursive solution needs a base case and progress toward that case.

Base case

Stops the recursive calls.

Recursive case

Reduces the problem and calls the function again.

Factorial algorithm

factorial(n) = 1 when n ≤ 1; otherwise n * factorial(n-1).

long factorial(int n) {
    if (n <= 1) {
        return 1;       /* base case */
    }
    return n * factorial(n - 1);
}

For factorial(4): 4 × factorial(3) → 4 × 3 × factorial(2) → 4 × 3 × 2 × factorial(1) → 24.

5. Queue — FIFO

A queue follows FIFO (First In, First Out). Insert at REAR and remove from FRONT. Applications include ticket lines, printer queues, server requests and network buffers.

Linear queue representation

#define MAX 5
int q[MAX];
int front = -1, rear = -1;

Enqueue algorithm

  1. If rear == MAX−1, report overflow.
  2. If front == −1, set front = 0.
  3. Increment rear and store Q[rear] = item.

Dequeue algorithm

  1. If front == −1 or front > rear, report underflow.
  2. Save Q[front].
  3. If front == rear, reset both to −1; otherwise increment front.

Enqueue flowchart logic

START→rear == MAX−1?YES →OVERFLOW→STOP

NO: if front == −1 set front=0 → rear++ → Q[rear]=item → STOP.

Dequeue flowchart logic

START→Queue empty?YES →UNDERFLOW→STOP

NO: item=Q[front] → if front==rear reset both to −1, else front++ → return item → STOP.

Linear queue C code snippets

void enqueue(int item) {
    if (rear == MAX - 1) {
        puts("Queue Overflow");
        return;
    }
    if (front == -1) front = 0;
    q[++rear] = item;
}

void dequeue(void) {
    if (front == -1 || front > rear) {
        puts("Queue Underflow");
        return;
    }
    printf("Removed: %d\\n", q[front]);
    if (front == rear) front = rear = -1;
    else front++;
}

Circular queue

Empty: front == -1. Full: (rear + 1) % MAX == front. The modulo operator lets indices wrap around and reuse freed slots.

/* Circular enqueue */
if ((rear + 1) % MAX == front) {
    puts("Queue Overflow");
    return;
}
if (front == -1) front = rear = 0;
else rear = (rear + 1) % MAX;
q[rear] = item;

/* Circular dequeue */
if (front == -1) {
    puts("Queue Underflow");
    return;
}
int item = q[front];
if (front == rear) front = rear = -1;
else front = (front + 1) % MAX;

Deque and priority queue

Deque: insertion and deletion can happen at both ends. Input-restricted deque limits insertion to one end; output-restricted deque limits deletion to one end.

Priority queue: items are served according to priority rather than arrival order alone. Examples include hospital triage and task scheduling. Define a tie-breaking rule for equal priorities.
