What a linked list is

A linked list keeps its items in separate nodes. Each node holds a value and the address of the next node, so the nodes can sit anywhere in memory. The program stores only the address of the first node, called head. Every other node is reached by following the links until a link holds NULL.

Open the other tabs to insert, delete, search and reverse. Each operation shows the exact pointer assignments it performs.

  • Size changes at run time. Nodes are created with malloc and returned with free.
  • Inserting or deleting at the front never moves other elements.
  • Reaching the k-th node means walking k links from the head.

Anatomy of a node

The hex number above each node is an example heap address. The arrow is the value stored in the next field: the address of the node it points to.

Four kinds of linked list

      

        
Singly
One link per node, forward only. Smallest memory cost. The base for stacks and queues.

        
Doubly
Each node also stores prev. You can walk both ways and unlink a node you already hold without searching for its predecessor.

        
Circular singly
The last node points back to the first, so no link is NULL. Used for round-robin scheduling and looping playlists.

        
Circular doubly
Circular and two-way: head->prev is the tail and tail->next is the head.

Singly linked list

        
Each node stores a value and one next pointer. You enter at head and can only move forward. The last node's next is NULL.

      

      
    
        
  • Insert at the beginning is two assignments, so it costs O(1).
    • 
        
  • Delete at the end needs a walk to the second-last node, because a node cannot look back.
    • 
        
  • Reverse flips every next pointer in a single pass with three helper pointers.
    • 
      

    

    

    

  


  
  

    

      

        
Doubly linked list

        
Each node adds a prev pointer. head->prev and tail->next are NULL. Orange labels mark the two entry points the program stores.

      

      
    
        
  • Every insert and delete repairs two links, not one.
    • 
        
  • With a tail pointer, insert and delete at the end are O(1).
    • 
        
  • The list can be printed backward by starting at tail.
    • 
      

    

    

    

  


  
  

    

      

        
Circular linked list

        
No link is NULL. The last node points back to the first, so a loop written as while (temp != NULL) would never stop. Traversal uses do { ... } while (temp != head) instead.

        
The singly version stores only last; the head is last->next, which makes insertion at both ends O(1). Switch the diagram and the program below with the toggle.

      

      
    
        
  • A single node points to itself. Treat that case separately when deleting.
    • 
        
  • Delete at the end of a circular singly list still needs a walk to find the node before last.
    • 
        
  • In the doubly version, head->prev gives the tail without storing it.
    • 
      

    

    

    

    

  


  
  

    

      

        
Stack using a linked list

        
A stack is last in, first out. With a linked list the head is the top: push inserts at the beginning and pop deletes from the beginning. Both are O(1), and there is no fixed capacity. Overflow only happens if malloc fails.

      

      
    
        
  • Underflow means popping when top == NULL.
    • 
        
  • Used for function calls, undo history and expression evaluation.
    • 
        
  • An array stack needs a size limit; this one does not.
    • 
      

    

    

    

  


  
  

    

      

        
Queue using a linked list

        
A queue is first in, first out. dequeue removes from the head (front) and enqueue adds at the tail (rear). Keeping a separate rear pointer avoids walking the whole list on every enqueue.

      

      
    
        
  • When the last element leaves, set rear = NULL as well as front.
    • 
        
  • Used for print jobs, task scheduling and breadth-first search.
    • 
        
  • Both operations are O(1).
    •
