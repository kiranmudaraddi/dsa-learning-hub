1. Pointers in C

A pointer is a variable that stores the memory address of another variable. Pointers are used to access data indirectly, pass addresses to functions, allocate memory dynamically and connect linked-list nodes.

Declaration and initialization

int number = 25;
int *ptr = &number;

printf("%d", number);  /* 25 */
printf("%d", *ptr);    /* 25: value at the address */
*ptr = 40;             /* number becomes 40 */
Remember: & obtains an object's address; * dereferences a pointer. Initialize a pointer before using it and check for NULL before dereferencing dynamically allocated memory.

Pointer arithmetic

int values[] = {10, 20, 30};
int *p = values;
printf("%d", *p);       /* 10 */
printf("%d", *(p + 1)); /* 20 */

Adding one to a pointer advances by the size of its pointed-to type. Pointer arithmetic is valid within an array object and one position past its end; the one-past pointer must not be dereferenced.

Pointer errors to avoid

  • Uninitialized pointer: may contain an invalid address.
  • NULL dereference: check allocation results.
  • Dangling pointer: do not use memory after it is freed.
  • Out-of-bounds access: remain within valid array/object limits.
  • Memory leak: release allocated memory when it is no longer needed.

2. Dynamic memory allocation

Dynamic memory is requested at runtime. Include <stdlib.h> to use the standard allocation functions.

FunctionPurposeImportant point
malloc(n)Allocates n bytesContents are uninitialized
calloc(count,size)Allocates an array of count elementsAllocated bytes are zero-initialized
realloc(ptr,n)Changes allocation sizeUse a temporary pointer to handle failure safely
free(ptr)Releases allocated memoryDo not access the block after freeing

Example: dynamic array

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n, i;
    if (scanf("%d", &n) != 1 || n <= 0) return 1;

    int *a = malloc((size_t)n * sizeof *a);
    if (a == NULL) {
        printf("Allocation failed\n");
        return 1;
    }

    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    for (i = 0; i < n; i++) printf("%d ", a[i]);

    free(a);
    a = NULL;
    return 0;
}

Safe realloc pattern

int *temp = realloc(a, (size_t)new_n * sizeof *a);
if (temp != NULL) {
    a = temp;
} else {
    /* a still refers to the original allocation */
}
Do not write a = realloc(a, ...) directly when a is your only pointer to the allocation. If realloc fails, the original block remains allocated but its address would be lost.

3. Self-referential structures

A self-referential structure contains a pointer to another structure of the same type. It cannot contain a direct member of its own type because that would require an infinitely large object.

struct Node {
    int data;
    struct Node *next;
};

The next member stores the address of another struct Node. This structure is the foundation of a singly linked list. A NULL next pointer means there is no next node.

4. Linked-list representation and types

A linked list is a dynamic linear data structure made of nodes. Each node contains data and one or more links. The head pointer identifies the first node.

head
 |
 v
+------+------+	+------+------+	+------+------+
|  10  |  o---+-->|  20  |  o---+-->|  30  | NULL |
+------+------+  +------+------+  +------+------+
Singly linked list

One next pointer; last node points to NULL.

Doubly linked list

prev and next pointers; traversal in both directions.

Circular singly linked list

Last node points back to the first node.

Circular doubly linked list

Previous and next links form a circle.

Linked-list nodes need not be contiguous in memory. Access by position requires traversal from the head, while insertion or deletion can be efficient when the required link is already known.

5. Singly linked list operations

Traversal / display

void display(struct Node *head)
{
    struct Node *current = head;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
}

Insert at beginning

void insertFront(struct Node **head, int value)
{
    struct Node *n = malloc(sizeof *n);
    if (n == NULL) return;
    n->data = value;
    n->next = *head;
    *head = n;
}

Time complexity: O(1). A pointer to the head pointer is used because the function may change the head itself.

Insert at end

void insertEnd(struct Node **head, int value)
{
    struct Node *n = malloc(sizeof *n);
    if (n == NULL) return;
    n->data = value;
    n->next = NULL;

    if (*head == NULL) {
        *head = n;
        return;
    }
    struct Node *cur = *head;
    while (cur->next != NULL) cur = cur->next;
    cur->next = n;
}

Without a tail pointer, insertion at end takes O(n). With a maintained tail pointer it can take O(1).

Delete first node

void deleteFront(struct Node **head)
{
    if (*head == NULL) return;
    struct Node *temp = *head;
    *head = (*head)->next;
    free(temp);
}

Delete first matching value

int deleteValue(struct Node **head, int key)
{
    struct Node *cur = *head, *prev = NULL;
    while (cur != NULL && cur->data != key) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return 0;
    if (prev == NULL) *head = cur->next;
    else prev->next = cur->next;
    free(cur);
    return 1;
}
OperationTimeReason
Search / access by positionO(n)Sequential traversal
Insert at headO(1)Update head link
Delete at headO(1)Move head and free old node
Insert at endO(n), or O(1) with tailFind final node if no tail
Delete at endO(n)Find predecessor

6. Doubly linked list

Each node contains data, a pointer to the previous node and a pointer to the next node. The first node has prev = NULL; the last node has next = NULL.

struct DNode {
    int data;
    struct DNode *prev;
    struct DNode *next;
};

Insert at front

void dInsertFront(struct DNode **head, int value)
{
    struct DNode *n = malloc(sizeof *n);
    if (n == NULL) return;
    n->data = value;
    n->prev = NULL;
    n->next = *head;
    if (*head != NULL) (*head)->prev = n;
    *head = n;
}

Delete a known node

void dDeleteNode(struct DNode **head, struct DNode *p)
{
    if (p == NULL) return;
    if (p->prev != NULL) p->prev->next = p->next;
    else *head = p->next;
    if (p->next != NULL) p->next->prev = p->prev;
    free(p);
}

Doubly linked lists allow backward traversal and O(1) deletion of a known node. They use extra memory and require careful maintenance of both links.

7. Circular linked list

In a circular singly linked list, the final node points to the head rather than NULL. Traversal must stop when it returns to its starting node.

void circularDisplay(struct Node *head)
{
    if (head == NULL) return;
    struct Node *cur = head;
    do {
        printf("%d ", cur->data);
        cur = cur->next;
    } while (cur != head);
}

Insert at end using a tail pointer

/* tail points to the last node; head is tail->next */
void circularInsertEnd(struct Node **tail, int value)
{
    struct Node *n = malloc(sizeof *n);
    if (n == NULL) return;
    n->data = value;
    if (*tail == NULL) {
        n->next = n;
        *tail = n;
    } else {
        n->next = (*tail)->next;
        (*tail)->next = n;
        *tail = n;
    }
}

With a tail pointer, insertion at the end is O(1). A one-node circular list points to itself. Always handle empty, one-node and multi-node cases separately.

8. Stack and queue using linked lists

Stack using linked list

A stack follows LIFO. Keep the top at the head so push and pop are O(1).

void push(struct Node **top, int value)
{
    struct Node *n = malloc(sizeof *n);
    if (n == NULL) return;
    n->data = value;
    n->next = *top;
    *top = n;
}

int pop(struct Node **top, int *out)
{
    if (*top == NULL) return 0; /* underflow */
    struct Node *temp = *top;
    *out = temp->data;
    *top = temp->next;
    free(temp);
    return 1;
}

Queue using linked list

A queue follows FIFO. Maintain front and rear pointers. Enqueue at rear and dequeue at front; both are O(1).

struct QueueNode {
    int data;
    struct QueueNode *next;
};
struct Queue {
    struct QueueNode *front, *rear;
};

void enqueue(struct Queue *q, int value)
{
    struct QueueNode *n = malloc(sizeof *n);
    if (n == NULL) return;
    n->data = value;
    n->next = NULL;
    if (q->rear == NULL) q->front = q->rear = n;
    else { q->rear->next = n; q->rear = n; }
}

int dequeue(struct Queue *q, int *out)
{
    if (q->front == NULL) return 0;
    struct QueueNode *temp = q->front;
    *out = temp->data;
    q->front = temp->next;
    if (q->front == NULL) q->rear = NULL;
    free(temp);
    return 1;
}
When the last queue node is removed, set both front and rear to NULL. Always check underflow and allocation failure.

9. Case study: Music Playlist Manager

Problem: Build a playlist in which users can add a song, remove a song, play the next or previous song and repeat playback.

Data model: Each node stores a song ID/title and prev/next pointers. A current pointer identifies the playing song. A circular doubly linked list supports next/previous movement and repeat mode.

FeatureLinked-list operation
Add a songInsert a new node into the playlist
Remove a songReconnect neighbours and free the node
Next songMove current to current->next
Previous songMove current to current->prev
Repeat playlistCircular links wrap at the end/start

Edge cases: removing the only song makes the list empty; removing the current song should select a valid neighbour; a missing song should not change the playlist.

Other applications: browser back/forward history (doubly linked list), round-robin scheduling (circular list), dynamic memory free lists, undo/redo history and polynomial representation.
