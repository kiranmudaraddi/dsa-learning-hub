Stack: concept to implementation

A stack is a linear data structure that follows Last In, First Out (LIFO). In an array implementation, initialize top = -1 to represent an empty stack.

PUSH(x)If top == MAX−1, report overflow. Otherwise increment top and store x.
POP()If top == −1, report underflow. Otherwise return stack[top] and decrement top.
PEEK()Read stack[top] only if the stack is not empty.
InvariantValid top values range from −1 to MAX−1. Elements occupy stack[0] through stack[top].

Algorithm: PUSH(x)

  1. If top equals MAX − 1, report Stack Overflow.
  2. Otherwise set top = top + 1.
  3. Set stack[top] = x.

Complete C program

This is a self-contained example for GCC/Clang-style C compilers. It checks overflow and underflow explicitly.

#include <stdio.h>
#define MAX 5

int stack[MAX];
int top = -1;

void push(int value) {
    if (top == MAX - 1) {
        printf("Stack Overflow\n");
        return;
    }
    stack[++top] = value;
}

int pop(int *value) {
    if (top == -1) {
        printf("Stack Underflow\n");
        return 0;
    }
    *value = stack[top--];
    return 1;
}

int main(void) {
    int value;
    push(10);
    push(20);
    push(30);
    if (pop(&value))
        printf("Popped: %d\n", value);
    printf("Top: %d\n", stack[top]);
    return 0;
}

Expected output

Popped: 30
Top: 20

Common mistakes to avoid

  • Using top == MAX as the overflow test; the last valid index is MAX - 1.
  • Decrementing top before reading the popped value.
  • Calling PEEK or POP on an empty stack without checking underflow.
  • Forgetting #include <stdio.h> when using printf().
