# DSA Learning Hub — GitHub Pages

A static learning portal for Data Structures and Applications (1BCS305), III Semester CSE (AI). It includes a landing page, the Module 1–2 theory PDF, interactive infix-to-postfix conversion, postfix evaluation, stack simulators, vehicle parking stack case study, and a recursion teaching lab.

## Publish at GitHub Pages

1. Create a new GitHub repository named `dsa-learning-hub` (or another name you prefer).
2. Upload **all files and folders inside this package** to the repository root. Keep `index.html` at the root and keep the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. The URL will look like `https://YOUR-USERNAME.github.io/dsa-learning-hub/`.

If the repository is named `YOUR-USERNAME.github.io`, the site will instead be published at the root URL `https://YOUR-USERNAME.github.io/`.

## Before publishing

- Test `index.html` locally by opening it in a browser.
- Check that the PDF opens and every interactive tool link works.
- If you use a different repository name, links within this site remain relative and do not need to be edited.
